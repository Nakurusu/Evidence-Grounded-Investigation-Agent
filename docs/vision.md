# AI Investigative Analyst

## Vision

Build an AI-powered investigative analyst that helps users discover problems, narrow down possible causes, generate hypotheses, and guide further investigation from arbitrary datasets.

The system is not designed to replace analysts.

Instead, it acts as an intelligent investigative partner that accelerates the analytical process.

---

## Problem Statement

Traditional analytics tools focus on reporting:

- What happened?
- How much happened?

However, users often need help answering:

- Why did it happen?
- What should I investigate next?
- What additional data do I need?

This project aims to bridge that gap.

---

## Core Value

The system should help users:

1. Understand their data.
2. Discover important signals.
3. Generate investigative questions.
4. Produce evidence-backed hypotheses.
5. Recommend next steps.

---

## User Modes

### Question-driven

The user has a specific question.

Examples:

- Why did revenue decline?
- Which regions underperformed?
- What caused customer churn?

---

### Exploration-driven

The user has no predefined question.

Examples:

- Analyze this dataset.
- What should I pay attention to?
- Are there any risks or opportunities?

---

## Long-term Goal

Transform raw datasets into structured investigations.

Data
→ Questions
→ Hypotheses
→ Evidence
→ Conclusions
→ Next Actions
